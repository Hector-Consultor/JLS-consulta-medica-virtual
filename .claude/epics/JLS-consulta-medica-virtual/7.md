# Task: Landing page del Dr. Salazar

## Description
Crear y publicar la página web pública del Dr. Juan Luis Salazar en la plataforma seleccionada (Google Sites / Wix / Carrd / Netlify). La landing page es la presencia digital del médico e incluye toda la información necesaria para que el paciente confíe en el servicio y llegue al formulario de agendamiento.

## Acceptance Criteria
- [ ] Página publicada en la plataforma seleccionada con dominio personalizado o URL limpia
- [ ] Sección "Sobre el Dr. Salazar": nombre completo, especialidad (Médico Internista Especialista), países de licencia (Colombia, Venezuela), breve descripción profesional
- [ ] Sección "¿Cómo funciona?": pasos visuales del proceso (agenda → paga → consulta → informe)
- [ ] Sección "Servicios": descripción de la consulta virtual, qué incluye (asesoría, segunda opinión, seguimiento), duración estimada
- [ ] Tarifa de consulta visible antes de cualquier acción de agendamiento
- [ ] Política de cancelación visible en la página: "No hay reembolso si el paciente cancela. Podés cancelar con mínimo 24 horas de anticipación."
- [ ] Botón/CTA principal "Agendar consulta" que redirige a la URL del Web App de Apps Script (booking.html)
- [ ] Sección de contacto o información de respaldo (email del médico)
- [ ] Footer con: aviso de privacidad, términos y condiciones (links a documentos externos), y nota de regulación (licencia CO y VE)
- [ ] Diseño responsivo: funcional en mobile y desktop
- [ ] Tiempo de carga < 3 segundos

## Technical Details
- La plataforma es **a definir por el cliente** (ver análisis de alternativas en PRD)
- La integración con el backend de agendamiento se logra con un simple link/botón a la URL del Web App — no se requiere integración técnica compleja en el frontend
- Si la plataforma es **Google Sites**: embeber el Web App de Apps Script como iframe es posible y simplifica el flujo
- Si la plataforma es **Netlify**: es una landing estática con CTA que abre el Web App en nueva pestaña o modal
- El dominio debe apuntar a la plataforma elegida (configuración DNS)
- Archivos afectados: configuración de la plataforma seleccionada (fuera del proyecto Apps Script)

**⚠️ BLOQUEANTE:** Requiere que el cliente haya seleccionado la plataforma web y definido la tarifa de consulta.
