# Task: Flujo de cancelación con validación 24h

## Description
Implementar el flujo completo de cancelación autónoma por parte del paciente (con validación de 24h y política de no reembolso) y la detección automática de cancelaciones por parte del médico desde Google Calendar. Incluye la página de cancelación y todos los emails asociados.

## Acceptance Criteria

**Cancelación por paciente:**
- [ ] `cancelacion.html`: página que carga los datos de la cita a partir del token en la URL (GET /?page=cancelar&token=UUID)
- [ ] El sistema valida que el token exista en Sheets y corresponda a una cita en estado "confirmado"
- [ ] El sistema valida que falten **más de 24 horas** para la fecha/hora de la cita
  - Si < 24h: mostrar mensaje bloqueante "Esta cita ya no puede cancelarse ni modificarse. Comunicate con el médico si tenés una emergencia." Sin botón de confirmar.
  - Si ≥ 24h: mostrar datos de la cita y advertencia de no reembolso
- [ ] Checkbox obligatorio en la página: "Entiendo que al cancelar esta cita no recibiré reembolso del pago realizado"
- [ ] Al confirmar: actualizar Sheets (estado → "cancelado_paciente", cancelado_por → "paciente"), eliminar o cancelar evento en Google Calendar, invalidar el token
- [ ] Email al paciente: confirmación de cancelación, recordatorio de no reembolso
- [ ] Email al médico: notificación de cancelación con datos del paciente

**Cancelación por médico:**
- [ ] `Cancelaciones.gs`: función `detectarCancelacionMedico()` que se activa como trigger de Calendar
- [ ] Si el médico elimina o cancela un evento que tiene id en Sheets (estado "confirmado"): actualizar Sheets (estado → "cancelado_medico", cancelado_por → "medico")
- [ ] Email al paciente: "El Dr. Salazar ha cancelado tu cita del [fecha]. Podés reprogramar [link agenda] o solicitar el reembolso [instrucciones]."
- [ ] Email al médico: recordatorio de gestionar el reembolso si es solicitado

**General:**
- [ ] Token de cancelación funciona una sola vez (se invalida tras usarse)
- [ ] Estados diferenciados en Sheets: "cancelado_paciente" vs "cancelado_medico"

## Technical Details
- La validación de 24h se calcula en el servidor (Apps Script), no en el cliente
- Usar `new Date()` en timezone UTC-5 para el cálculo: `(fechaCita - new Date()) / (1000*60*60) >= 24`
- Para detectar cancelación del médico: Apps Script trigger `onEventUpdated` de Calendar (puede ser trigger de tiempo como alternativa si el trigger de evento no está disponible)
- El token se invalida seteando el campo token_cancelacion a null/vacío en Sheets tras la cancelación
- Archivos afectados: Cancelaciones.gs, Emails.gs, SheetsService.gs, CalendarService.gs, Code.gs (doGet), pages/cancelacion.html
