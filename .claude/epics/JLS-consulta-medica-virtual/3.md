# Task: Disponibilidad y formulario de agendamiento

## Description
Implementar la lectura de disponibilidad desde Google Calendar y la página de agendamiento (booking.html) que el paciente usa para seleccionar fecha/hora y completar sus datos. Al enviar el formulario, se crea el registro en Google Sheets con estado "pendiente_pago" y se redirige a la pasarela de pago.

## Acceptance Criteria
- [ ] `CalendarService.gs`: función `getAvailableSlots(fechaInicio, fechaFin)` que lee el Calendar del médico y retorna slots libres (no ocupados por eventos existentes)
- [ ] Los slots se muestran en zona horaria UTC-5 (Colombia/Venezuela)
- [ ] `booking.html`: formulario responsivo con campos nombre, email, teléfono, país (Colombia/Venezuela/Otro), motivo de consulta
- [ ] `booking.html`: checkbox obligatorio de política de no reembolso antes de proceder al pago: "Entiendo que si cancelo esta cita, no recibiré reembolso del pago realizado"
- [ ] `booking.html`: selector de fecha/hora que solo muestra slots disponibles (no reservados)
- [ ] Al enviar el formulario: validación de campos obligatorios y formato de email
- [ ] `Agenda.gs`: función `registrarCita(datos)` que genera UUID, crea registro en Sheets con estado "pendiente_pago", retorna id_turno
- [ ] Tras el registro, el formulario redirige al paciente a la URL de la pasarela con el id_turno como referencia
- [ ] Slots ya reservados (estado confirmado en Sheets) no aparecen como disponibles
- [ ] Diseño responsivo funcional en mobile y desktop

## Technical Details
- Usar `Utilities.getUuid()` para generar id_turno
- `CalendarService.getAvailableSlots()` debe cruzar eventos del Calendar del médico con registros confirmados en Sheets para determinar disponibilidad real
- El formulario es un HTML estático servido por Apps Script HTML Service (`HtmlService.createHtmlOutputFromFile('pages/booking')`)
- La comunicación formulario→Apps Script usa `google.script.run` (si el form es servido por Apps Script) o fetch POST a la URL del Web App
- Zona horaria: siempre mostrar UTC-5, almacenar en Sheets como ISO 8601 con offset -05:00
- Archivos afectados: CalendarService.gs, Agenda.gs, SheetsService.gs, Code.gs (doGet), pages/booking.html
