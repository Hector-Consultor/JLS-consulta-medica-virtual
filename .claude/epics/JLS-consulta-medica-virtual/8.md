# Task: Template de informe post-consulta

## Description
Crear el template estandarizado de Google Docs para el informe de recomendaciones que el médico completa tras cada consulta, y configurar la estructura de Google Drive para archivar los informes de forma organizada. En MVP, el médico completa y envía el informe manualmente.

## Acceptance Criteria
- [ ] Template de Google Docs creado y guardado en Google Drive del médico
- [ ] El template incluye los siguientes campos pre-completados automáticamente (o fácilmente completables): nombre del paciente, email, fecha de la consulta, nombre del médico (Dr. Juan Luis Salazar, Médico Internista)
- [ ] El template incluye secciones: Motivo de Consulta (pre-llenado), Antecedentes relevantes mencionados, Evaluación clínica y orientación, Recomendaciones (campo principal, texto libre), Estudios o consultas sugeridas, Seguimiento recomendado, Disclaimers legales ("Este informe es de carácter orientativo, no reemplaza la atención médica presencial ni constituye una prescripción")
- [ ] Estructura de carpetas en Google Drive: `/Consultas JLS / [AÑO] / [MES] / Informe - [APELLIDO] - [FECHA].docx`
- [ ] Apps Script: función `crearInformeDesdeTemplate(idTurno)` que crea una copia del template en la carpeta correcta con los datos del paciente pre-llenados desde Sheets
- [ ] El médico puede activar la creación del informe manualmente desde una función en Apps Script (o desde la Sheets con un botón/menu personalizado)
- [ ] Instrucciones de uso documentadas para el médico (en el propio archivo de config o en un doc de instrucciones)

## Technical Details
- Usar `DriveApp.getFileById(TEMPLATE_ID).makeCopy(nombre, carpeta)` para crear copias del template
- Usar `DocumentApp.openById(id)` para reemplazar placeholders con datos reales del paciente
- Placeholders en el template con formato `{{nombre}}`, `{{fecha}}`, `{{motivo}}` para reemplazo programático
- La función `crearInformeDesdeTemplate` puede ser invocada manualmente por el médico o desde el menú personalizado en Sheets
- Agregar TEMPLATE_ID y DRIVE_FOLDER_ID a Config.gs
- Archivos afectados: nuevo archivo `Informes.gs`, Config.gs, SheetsService.gs
