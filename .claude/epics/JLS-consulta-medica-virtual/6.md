# Task: Recordatorios automáticos 24h antes

## Description
Implementar el sistema de recordatorios automáticos que envía un email al paciente y al médico exactamente 24 horas antes de cada cita. El sistema usa un time-based trigger de Apps Script que corre cada hora y detecta citas en la ventana de 24-25 horas.

## Acceptance Criteria
- [ ] `Recordatorios.gs`: función `enviarRecordatoriosHorarios()` que filtra citas confirmadas cuya fecha_hora esté entre NOW+24h y NOW+25h
- [ ] Email al paciente con: fecha/hora (UTC-5), link de Google Meet, instrucciones de conexión técnica (tener cámara y micrófono listos, conexión estable, ingresar 5 min antes), y aviso explícito: "Ya no es posible cancelar ni modificar esta cita"
- [ ] Email al médico con: fecha/hora, nombre del paciente, email, motivo de consulta
- [ ] Tras enviar el recordatorio: actualizar columna `recordatorio_enviado` en Sheets con "si" y el timestamp de envío
- [ ] El sistema no envía recordatorio duplicado si ya está marcado como enviado en Sheets
- [ ] Time-based trigger configurado para ejecutar cada hora
- [ ] Registro de errores en Sheets si falla el envío (columna `recordatorio_enviado` → "error")

## Technical Details
- Usar `ScriptApp.newTrigger('enviarRecordatoriosHorarios').timeBased().everyHours(1).create()` para configurar el trigger
- La ventana de detección es 24h a 25h para evitar que una cita sea detectada en múltiples runs del trigger
- Cálculo: `fechaCita >= new Date(Date.now() + 24*60*60*1000)` y `fechaCita < new Date(Date.now() + 25*60*60*1000)`
- Filtrar solo citas con estado "confirmado" y recordatorio_enviado !== "si"
- El trigger se configura UNA SOLA VEZ (idempotente: verificar si ya existe antes de crear)
- Archivos afectados: Recordatorios.gs, Emails.gs, SheetsService.gs
