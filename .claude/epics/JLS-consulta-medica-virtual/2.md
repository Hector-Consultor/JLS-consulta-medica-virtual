# Task: Setup base del proyecto Apps Script

## Description
Crear y configurar el proyecto Google Apps Script como Web App, establecer la estructura de Google Sheets como base de datos, y centralizar todos los parámetros de configuración en Config.gs. Esta tarea es el fundamento de todo el sistema.

## Acceptance Criteria
- [ ] Proyecto Apps Script creado en Google Drive del médico con nombre "JLS-Consulta-Medica"
- [ ] Estructura de archivos .gs creada: Code.gs, Config.gs, SheetsService.gs, CalendarService.gs, Agenda.gs, Pagos.gs, Cancelaciones.gs, Recordatorios.gs, Emails.gs
- [ ] Carpeta `pages/` creada con placeholders para booking.html y cancelacion.html
- [ ] Google Sheets creado con hoja `consultas` y todas las columnas definidas: id_turno, nombre, email, telefono, pais, motivo, fecha_hora, estado, id_evento_calendar, link_meet, token_cancelacion, cancelado_por, reembolso_solicitado, recordatorio_enviado, fecha_registro
- [ ] Config.gs con todas las constantes: SHEET_ID, CALENDAR_ID, EMAIL_MEDICO, TARIFA_COP, TARIFA_USD, HORAS_MIN_CANCELACION (24), URL_WEB_APP
- [ ] Web App desplegada en modo "Cualquier persona" con acceso de ejecución "Yo"
- [ ] Permisos OAuth concedidos: Sheets, Calendar, Gmail, Drive
- [ ] doGet básico en Code.gs respondiendo a peticiones GET
- [ ] Función de test de conexión que valida acceso a Sheets y Calendar

## Technical Details
- Usar `SpreadsheetApp.openById(SHEET_ID)` para acceso a Sheets
- Usar `CalendarApp.getCalendarById(CALENDAR_ID)` para Calendar
- Config.gs debe exportar un objeto CONFIG con todas las constantes
- El Web App debe desplegarse como nueva versión para cada cambio significativo
- Mantener IDs sensibles en Script Properties (no hardcodeados en código)
- Archivos afectados: todos los .gs del proyecto (creación inicial)

## Dependencies
- [ ] Cuenta Google Workspace del médico activa
- [ ] Google Calendar del médico con horarios de disponibilidad cargados
- [ ] Tarifa de consulta definida (para Config.gs)
